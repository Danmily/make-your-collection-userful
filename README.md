# 重遇 · Resurface

> 不是更好的收藏夹，是一个会替你记得的收件箱。

大部分「收藏管理」产品都在解决**取不出**——搜索更聪明、标签更自动。但真正丢掉的内容，是你**压根不记得自己存过**的那些。给一个你不会打开的抽屉配一把更好的锁，没有用。

重遇把重心从「被动检索」挪到「主动重遇」：不等你想起来去搜，而是每天按你手上有多少时间，把该浮上来的几条推到你面前，并且说清楚**为什么是现在**。

[在线演示](https://claude.ai/code/artifact/9aa9c4fe-deac-421c-bb00-07e21ae5ff9b) · 单文件、零依赖、数据只存在浏览器本地。

## 四个引擎

### 1. 重遇（主引擎）

首页没有搜索框。先问你现在有多少时间——通勤 10 分钟、午休 30 分钟、还是一整块。然后打分：

```
score = 遗忘曲线 × 意图权重 × 冷落加成 × 时间档匹配 × 每日扰动
```

| 因子 | 做什么 | 实现 |
|---|---|---|
| 遗忘曲线 | 太新的还记得，不用推；太老的已失效 | `(1 - e^(-a/12)) · e^(-a/260)` |
| 意图权重 | 「想动手」比「备查」更该被翻出来 | 动手 1.25 / 学习 1.15 / 备查 0.55 |
| 冷落加成 | 一次没打开过的优先 | 未读 ×1.35，已读 ×0.35 |
| 时间档匹配 | 时长贴近你选的空档 | 以预算为中心的高斯衰减 |
| 每日扰动 | 同一天内稳定，隔天换一批 | `hash(id + 日期)` 决定 |

每张卡都带一句「为什么现在给你看」，取自贡献最大的那个因子——不是装饰文案，是打分结果的解释。

### 2. 专题聚簇

你在三个月里、四个 app 上零散存的 6 条家装内容，存的时候互不相干，聚到一起才看得出你在琢磨什么。主题会互相套娃（「配色」的多数条目也在「家装」里），所以从大到小贪心取，重叠超 60% 的并入已有专题，不单开一组。

### 3. 追问

兜底能力。中文 bigram 匹配，标题权重 3 / 主题 2.5 / 备注 2 / 正文 1，带命中高亮，可按来源、意图、时间、长短过滤。

### 4. 腐烂检测

收藏夹应该会瘦，不该只会胖。标题带过期年份、或存了 10 个月以上一次没碰的，会主动找你，支持一键清理。

另外在入库时做标题相似度比对，撞了就提示「你存过类似的」——零成本触发一次重遇。

## 数据从哪来

- **导入浏览器书签**：Netscape 书签 HTML（Chrome / Edge / Safari 导出的那种）。读 `ADD_DATE` 还原真实收藏时间，读上层 `<H3>` 作为文件夹线索。**全程在浏览器本机解析，不上传。**
- **粘链接**：域名判定来源与类型，标题和「你为什么存它」那句备注需要手填。

存储用 `localStorage`，清掉浏览器数据即清空。有一份 30 条的示例收藏可随时用「恢复示例数据」还原。

## 现在哪些是假的

说明白，免得误会这是个成品：

| 能力 | 现在 | 接后端之后 |
|---|---|---|
| 正文获取 | 无（只有标题+备注） | 抓取网页正文、视频字幕 |
| 意图 / 时长 / 主题 | 正则规则 | 模型抽取 |
| 追问 | bigram 字面重叠 | 向量 + 关键词双路召回，RRF 融合 |

打分函数、重遇逻辑、聚类合并这些产品层的东西不受影响，可以原样保留。

## 跑起来

单个 HTML 文件，没有构建步骤。

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。直接双击 `index.html` 也行。
